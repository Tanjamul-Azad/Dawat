# Compact client workflow — 20 October 2026

Implemented after the user requested the remaining product work while away, with UI/UX focused on compact hierarchy, clear actions and Bengali as the primary language. This is functional implementation evidence; it does not certify a public launch or fresh browser/device rendering.

## Delivered

- Contextual navigation: current wedding's editor and guest desk are directly accessible; the active location is accurate. Dashboard gives each active wedding an edit action and guest shortcut, plus honest inactive/expired states. Compact panels, bounded text, smaller spacing and responsive seller rows retain 44px controls and the existing Jamdani artwork/template.
- Acknowledged autosave after two seconds idle. Each request captures a content snapshot/revision; typing remains available and later edits stay dirty after an earlier acknowledgement. Uploads and conflicting commands cannot race the save. Failure pauses automatic retries, retains text and exposes manual retry. A conflicting remote version is displayed as readable wedding details; keeping local edits requires a deliberate save before replacing the remote draft. Unload protection includes pending media/save state.
- Loading/retry boundaries for dashboard, editor and seller desk. Next's `retry` refetches the failed segment. Anonymous protected-page navigation redirects before streaming a loading shell. JSON requests time out after 30s (including body reading); uploads have a separate 120s bound, retain retry identity, and require a matching ready acknowledgement. No automatic replay of uncertain mutations.
- Host corrections: one event per command, unchanged household/policy/response revisions, reason required, original reply retained and actor/source recorded. Closed-policy override is explicit; invited scope and allowance still apply. History shows before/after, source, time, reason and override. Guest writes after a correction must refresh rather than silently overwrite it.
- Private CSV: full selected event/name/status scope across pages; max 10,000 rows and explicit refusal beyond the bound. Bengali headers, Unicode BOM, quoted newlines/quotes and formula neutralization after whitespace/control/directional prefixes. Includes source and UTC snapshot; excludes personal credentials and private host notes. Auth on every download, private/no-store, auditable, no persistent export object. Failure leaves the guest desk in place.
- Pause/resume: confirmation states guest-facing impact, retains replies/wishes/links/publication and never extends the hosting term. Protected guest content/media deny reads while paused. Publication revision and policy revision prevent stale commands. Resuming restores existing valid personal links.
- Seller name/email search is server-side, bounded and literal (wildcards escaped), under existing MFA/session authorization. Changed filters reset cursors; failed report refresh retains the prior scope/data. Visible amounts use BDT; Bengali decimals convert exactly to integer paisa without rounding.

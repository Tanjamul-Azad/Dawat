# অর্ডারের ইমেইল চালু করার নিয়ম

এটা চালু হলে দাওয়াত নিজে থেকে এই ইমেইলগুলো পাঠাবে:

| কখন | কাকে |
| --- | --- |
| নতুন অর্ডারের অনুরোধ এলে | অ্যাডমিন |
| নতুন পেমেন্ট যাচাইয়ের জন্য এলে | অ্যাডমিন |
| কাস্টম অর্ডারে দাম ও শর্ত পাঠালে | গ্রাহক |
| পেমেন্ট মিলে আয়োজনের পাতা চালু হলে, লিংকসহ | গ্রাহক |
| পেমেন্ট মিললে (পাতা পরে চালু হলে) | গ্রাহক |
| পেমেন্ট না মিললে, কারণসহ | গ্রাহক |

ইমেইল না গেলেও অর্ডারের কোনো কাজ আটকাবে না। তখন অ্যাডমিন আগের মতো "WhatsApp-এ জানান" দিয়ে জানাবেন।

## ১. আলাদা একটা Gmail খুলুন (৫ মিনিট)

**লগইন কোড যে Gmail থেকে যায়, সেটা ব্যবহার করবেন না।** বেশি ইমেইল গেলে Google ওই অ্যাকাউন্ট সাময়িক আটকে দিতে পারে, তাতে গ্রাহকদের লগইনও বন্ধ হয়ে যাবে।

১. নতুন Gmail খুলুন, যেমন `dawat.notify@gmail.com`।

২. https://myaccount.google.com/security খুলে **2-Step Verification** চালু করুন।

৩. https://myaccount.google.com/apppasswords খুলুন। নাম দিন `Dawat`, তারপর **Create** চাপুন। ১৬ অক্ষরের একটা পাসওয়ার্ড দেখাবে। এটা কপি করুন।
- এটা Gmail-এর আসল পাসওয়ার্ড নয়। শুধু এই কাজের জন্য, আর যেকোনো সময় মুছে ফেলা যায়।
- কাউকে পাঠাবেন না, চ্যাটেও দেবেন না।

## ২. Netlify-তে বসান

Netlify → `dawatcard` → Project configuration → Environment variables → **Add a variable**। নিচের চারটা বসান।

| নাম | মান | গোপন? |
| --- | --- | --- |
| `MAIL_SMTP_USER` | নতুন Gmail ঠিকানা, যেমন `dawat.notify@gmail.com` | না |
| `MAIL_SMTP_PASSWORD` | ধাপ ১-এর ১৬ অক্ষরের App Password (ফাঁকা জায়গা থাকলেও চলবে) | **হ্যাঁ, "Contains secret values" টিক দিন** |
| `MAIL_FROM` | `দাওয়াত <dawat.notify@gmail.com>` (ঐচ্ছিক) | না |
| `MAIL_ADMIN_TO` | যে ইমেইলে অ্যাডমিনের খবর যাবে। একাধিক হলে কমা দিয়ে লিখুন। | না |

## ৩. নতুন করে deploy করুন

Env বদলালে নতুন deploy লাগে। এই দুটোর যেকোনো একটা করুন:
- Netlify → Deploys → **Trigger deploy → Deploy project**।
- অথবা পরের push-এর commit-এর প্রথম লাইনে `[deploy]` লিখুন।

## ৪. পরীক্ষা করুন

১. নিজের আরেকটা ইমেইল দিয়ে সাইটে একটা টেস্ট অর্ডারের অনুরোধ পাঠান। কয়েক সেকেন্ডের মধ্যে `MAIL_ADMIN_TO`-তে "নতুন অর্ডারের অনুরোধ" আসার কথা।

২. প্রথম কয়েকটা ইমেইল Spam-এ যেতে পারে। সেগুলোতে **Not spam** চাপুন, আর নতুন Gmail ঠিকানাটা contacts-এ রাখুন।

৩. কিছু না এলে Netlify → Logs → Functions-এ `Notification email failed` খুঁজুন।
- `EAUTH` মানে App Password ভুল।
- অন্য কিছু দেখলে Claude-কে জানান।

## সীমা

সাধারণ Gmail থেকে দিনে প্রায় ৫০০ জনকে পাঠানো যায়। দাওয়াত প্রতি অর্ডারে মাত্র কয়েকটা ইমেইল পাঠায়, তাই এখন যথেষ্ট। পরে নিজের ডোমেইন নিলে Resend বা Brevo-এর মতো সেবায় সরানো যাবে, তখন ইমেইল Spam-এ কম যাবে।

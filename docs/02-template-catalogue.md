# Template catalogue

> This catalogue preserves the first-pass design inventory. The 19 October pass additionally archived all 27 listed 3D product wrappers; see [local page index](reference-evidence/page-index.md). Current implementation scope is in [plan.md](../plan.md).

Snapshot: **18 October 2026**. This is a reference inventory, not an asset library. Descriptions below are brief design classifications. Use original artwork and original theme names for the new product.

**Coverage:** every wedding and classic Save the Date product route listed below was opened. Product-page inspection is not a promise that every embedded animation completed. All ten e-Nimontron invitation pages were also surveyed for their guest controls. The 3D list was inventoried from its collection; only Arabian Palace was opened individually.

## Proposed original launch collection

These are **new concepts** for our brand. Start production with one end-to-end theme, then expand to six using the same renderer.

| Working name | Palette / motifs | Opening concept | Best fit |
|---|---|---|---|
| Jamdani Ivory | Ivory, antique gold, woven geometric flowers | Paper envelope and woven border | Elegant Bengali wedding/reception |
| Holud Utsab | Turmeric yellow, marigold orange, leaf green | Flower strings part gently | Gaye holud / mehendi |
| Royal Nikah | Emerald, ivory, muted brass, arch geometry | Two illustrated arch doors | Nikah / walima |
| Lal–Shada Biye | Vermilion, chalk white, alpana/paan details | Folded invitation and alpana reveal | Bengali Hindu wedding |
| Mughal Garden | Rose, sage, sandstone, courtyard/jali motifs | Garden gate or paper layers | Formal wedding / reception |
| Modern Desi | Warm neutral, deep ink, strong Bangla typography | Simple paper fade/slide | Minimal wedding, mixed-language families |

Religious text and ceremonial symbols are optional content choices, not automatically applied to everyone. Each theme needs a photo-free version and an animation-light version.

## Rules future work must preserve

- Mark observed, advertised, unknown and proposed separately.
- Do not claim paid/back-office behaviors were tested.
- Do not copy competitor artwork, brand names, testimonials, code or scarcity claims into our product.
- Payment success redirects never grant entitlements; use verified server-side provider confirmation.
- Tenant ownership is enforced on the server/database, not only in the UI.
- Preview and live pages use the same renderer and pinned template version.
- Draft edits must not silently alter the published card.
- Public guest payloads exclude private responses, contacts not selected for publication and owner records.
- Household tokens are bearer credentials: random/revocable, hash verified, never plaintext at rest/logged. **ADR A15 supersedes the hash-only recovery proposal:** authenticated encrypted ciphertext with a dedicated versioned server key permits owner-authorized recopy; copying never silently rotates/breaks previous shares. Keys/backups/rotation follow the personalization and production specs.
- Bangla typography must preserve shaped words/conjuncts; no naive character-splitting animation.
- Publication, payment, fulfilment, hosting expiry and RSVP closure are separate states.
- Invitations remain useful when animation/audio fails.
- Do not re-scan the reference sites just to recover a requirement already recorded here. Revisit only for a new user request or a concrete gap, not as a default starting step.
